# Configuration — Implemented

Configuration is `.env`-driven typed config under `src/config`. See
`.env.example` for defaults.

## Application
- `NODE_ENV`, `APP_NAME`, `LOG_LEVEL`, `PORT`, `APP_URL`, `API_URL`,
  `CORS_ORIGINS`, `APP_HOST`, Swagger settings.

## Database
- `DATABASE_URL`, `DATABASE_SLAVE_URL` (read replica).

## Cache (Redis)
- `REDIS_URL`, `CACHE_ENABLED`, `CACHE_DEFAULT_TTL_MS`, `CACHE_MAX_VALUE_BYTES`,
  `CACHE_KEY_PREFIX`, `CACHE_KEY_VERSION`.

## Messaging
- RabbitMQ: `RABBITMQ_URL`, `RABBITMQ_EXCHANGE`, `RABBITMQ_REGISTER_HANDLERS`.
- Kafka: `KAFKA_BROKERS`, `KAFKA_CLIENT_ID`, `KAFKA_GROUP_ID`.
- SQS: `SQS_URL`, `SQS_REGION`.

## Outbox
- `OUTBOX_POLL_INTERVAL_MS`, `OUTBOX_BATCH_SIZE`, `OUTBOX_MAX_ATTEMPTS`,
  `OUTBOX_RETRY_BASE_DELAY_MS`, `OUTBOX_RETRY_MAX_DELAY_MS`,
  `OUTBOX_CLAIM_LEASE_MS`, `OUTBOX_CLEANUP_OLDER_THAN_HOURS`.

## Scheduler
- `SCHEDULER_POLL_INTERVAL_MS`, `SCHEDULER_BATCH_SIZE`, `SCHEDULER_LOCK_TTL_MS`,
  `SCHEDULER_RECONCILIATION_INTERVAL_MS`, `SCHEDULER_WORKER_CONCURRENCY`,
  `SCHEDULER_JOB_ATTEMPTS`.

## Saga
- `SAGA_WORKER_LEASE_SECONDS`, `SAGA_CLAIM_BATCH_SIZE`, `SAGA_FAIRNESS_CAP`,
  `SAGA_SWEEP_INTERVAL_MS`, `SAGA_RETRY_BASE_DELAY_MS`,
  `SAGA_RETRY_MAX_DELAY_MS`, `SAGA_DEFAULT_MAX_ATTEMPTS`,
  `SAGA_INBOX_RETENTION_DAYS`.

## Inbox
- `INBOX_CLAIM_LEASE_MS`, `INBOX_MAX_ATTEMPTS`, `INBOX_RETRY_BASE_DELAY_MS`,
  `INBOX_RETRY_MAX_DELAY_MS`, `INBOX_RECONCILIATION_INTERVAL_MS`,
  `INBOX_PROCESSED_RETENTION_MS`.

## Batch operation (optional defaults)
- `BATCH_OPERATION_MAX_RECORDS_PER_JOB`, `BATCH_OPERATION_SYNC_THRESHOLD`,
  `BATCH_OPERATION_CHUNK_SIZE`, `BATCH_OPERATION_WORKER_CONCURRENCY`,
  `BATCH_OPERATION_CHUNK_ATTEMPTS`, `BATCH_OPERATION_RECONCILIATION_WINDOW_MS`,
  `BATCH_OPERATION_RESULT_SNAPSHOT_MAX_BYTES`.

## Import (optional defaults)
- `IMPORT_MAX_FILE_SIZE_BYTES`, `IMPORT_MAX_ROWS`, `IMPORT_SKIP_AV_SCAN`.

## Auth (JWT)
- `JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET`, `JWT_ACCESS_TTL`, `JWT_REFRESH_TTL`.

## Security / tenancy
- `SETTINGS_ENCRYPTION_KEY`, `THROTTLE_TTL_MS`, `THROTTLE_LIMIT`.
- `TENANCY_MODE` = `single` | `multi`.
- `IDEMPOTENCY_TTL_MS`, `IDEMPOTENCY_CLAIM_LEASE_MS`,
  `IDEMPOTENCY_REDIS_PREFIX`.
- `LOCK_DEFAULT_LEASE_MS`, `LOCK_MIN_LEASE_MS`, `LOCK_MAX_LEASE_MS`.
